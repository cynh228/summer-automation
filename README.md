## MNIST 手写数字识别

这是一个用 PyTorch 实现的全连接神经网络，在 MNIST 数据集上训练，用于识别 0-9 的手写数字。

### 模型结构
- 输入层：784 (28×28 展平)
- 隐藏层1：512 神经元 + ReLU
- 隐藏层2：512 神经元 + ReLU
- 输出层：10（对应数字 0-9）

### 训练参数
- 优化器：SGD，学习率 0.001
- 损失函数：交叉熵损失（CrossEntropyLoss）
- 批大小（batch size）：64
- 训练轮数（epochs）：5

### 最终结果
- 测试准确率：98.0%
- 测试平均损失：0.069749
